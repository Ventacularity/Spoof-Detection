# Detective Spoof: SPARC Voice Conversion Detection

An interpretable detector for voice-conversion spoofs generated by [SPARC](https://arxiv.org/abs/2406.12998), built from DSP-inspired physics features and a small ML ensemble. Final project for EE 123 (Digital Signal Processing), UC Berkeley.

**Authors:** Ved Sheth, Ching Yuen, Erick Lara

## Overview

SPARC converts a speaker's voice by swapping the speaker embedding and resynthesizing audio with a HiFi-GAN vocoder. Instead of using a black-box deep model, we target the known limitations of that vocoder with hand-designed spectral and temporal features, so every prediction can be explained in physical terms.

## Approach

1. **Preprocessing:** STFT with 25 ms frames, 10 ms hop, Hamming window (16 kHz audio).
2. **Features:** Seven candidate features, z-scored with training statistics:
   - Spectral flux (std, max): captures bursty consonant transitions
   - Modulation energy (2-10 Hz): captures natural jaw rhythm
   - Glottal residual (std, kurtosis) from a 16th-order LPC fit
   - Aliasing (mean, std) in the 5-8 kHz band: captures upsampling artifacts

   Glottal kurtosis was dropped (Cohen's d = 0.48, near-random pairwise consistency); the other six have d > 1.0 on both test sets.
3. **Classifiers:** Logistic regression (threshold 0.45, weighted toward spoof recall) and XGBoost (400 trees).
4. **Ensemble:** OR, AND, and AVG combinations of the two models' probabilities.

## Data

Built on the [VCTK corpus](https://datashare.ed.ac.uk/handle/10283/3443) (16 kHz). Models are trained on 1000 real vs. 1000 SPARC-converted clips (balanced). A separate 500-pair set with unseen target speakers is held out entirely for out-of-distribution testing.

## Results

| Setting | Best strategy | Accuracy |
|---|---|---|
| VCTK 1000-pair (in-distribution) | XGBoost | 99.1% |
| VC500 (out-of-distribution) | AVG ensemble | 94.7% |

On the out-of-distribution set, logistic regression reaches 94.2% and XGBoost 90.7%. The linear model generalizes better, and averaging the two gives the most robust result.

## Findings

- **Null result:** Phase variance showed no meaningful difference between real and spoofed speech (Cohen's d ~ 0), so we moved to spectral energy and modulation features.
- **Class balance matters:** Training on 2000 real vs. 1000 spoof dropped logistic regression to 67.9%; rebalancing restored it to 92.8%.

## Future Work

- Include target speakers in training to separate speaker style from synthesis artifacts
- Test against other synthesis systems (ElevenLabs, Tortoise TTS)
- Real-time detection
- Report EER and AUC-ROC to match ASVspoof evaluation standards
